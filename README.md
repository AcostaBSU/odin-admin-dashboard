# Odin Sign-Up Form

An HTML and CSS project that develops an admin dashboard

## Description

[Odin Admin Dashboard](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard) is the second project in the full-stack JavaScript portion of the [Odin Project](https://www.theodinproject.com/paths)
designed to give learners an opportunity to apply intermediate HTML and CSS concepts. In the project, you will find an HTML file that creates the entire DOM of the admin dashboard and a CSS file that styles the web page using only grid. The primary purpose of this project is to style and format a web page using only CSS grid in contrast to using only flexbox from previous lessons. Going forward, learning should see the value of each approach and have a better understanding of when to use either and even when to consider using both as a means to complement each other.
